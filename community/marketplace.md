## 官方 · 内核候选

军事：commander / warrior / commissar / scout / discipline  
梦：zuowang / paoding / xinhuo  
硅基：auditor  

其余为皮肤或实验。煤气灯、可爱媳妇、日系媳妇 **不进默认池**，仓库仍保留。

## 场景

| 场景 | 先试 |
|------|------|
| 连败 / 放弃 | military-warrior, military-commissar, shaman-linus |
| 破框 | shaman-musk, dream-zuowang |
| 产品 | shaman-jobs |
| 审查 | silicon-auditor, shaman-linus |
| 发散 | 庄周八梦航线，薪火收束 |

## 贡献

先交评测场景或某个内核角色的皮肤。新角色 PR 必须带 scorecard（有/无该角色在某一 evals 场景上的差），否则不进主池。

见 [CONTRIBUTING.md](CONTRIBUTING.md)。
