## 缘起：一个观察

人机多轮会话中，人类与 Agent 常常**双双陷入幻觉**。其病机可拆为三层：

```
收敛先验 → 强行收束 → 互证互强
```

1. **收敛先验**：LLM 的多轮会话训练数据多为「问题→澄清→解决」的收敛轨迹。模型遂内化一个错觉：**对话必然收敛**。
2. **强行收束**：真实的人机对话并非如此——人的念头流转不定，忽焉而东，忽焉而西。携「必收敛」先验的 Agent 会硬把发散的话题拉回轨道。
3. **互证互强**：人见 Agent 言之凿凿，遂顺其轨而行；Agent 见人并无异议，愈信其轨为真。共识层层加固，实则脱离实际——**双向幻觉**由此而生。

传销与邪教之洗脑，正是利用同一机制：**人为构造一条收敛轨道，把人的思维诱导到预设的错误定点**。

由此得一推论：收敛轨道本身可以被设计与引导——引向错误定点即为害，引向可能性边疆即为创造。此即 GHM 之立足点。

## 核心命题

> **被动幻觉是错误，主动幻觉是创造。**
> 幻觉不是 bug，是未被驯服的想象力。

PUAX 既有体系（诊断先行、信心门控、独立验证、防作弊）皆是「**防幻觉**」的收敛纪律。GHM 在其上补一层「**驭幻觉**」的发散引擎——阴阳互济，缺一不可。

**只有发散没有验证，是洗脑；只有验证没有发散，是过拟合。**

## 八术：从操控机制逆向工程为创造术

| 操控机制（暗面） | 认知原理 | GHM 正用 | 对应角色 |
|---|---|---|---|
| 爱的轰炸 | 高强度情绪激活卸下心理防备 | **轰炸术**：可能性轰炸，十条「若可能」齐发，延迟评判 | 梦蝶 |
| 登门槛效应 | 渐进承诺一致性 | **登阶术**：井蛙→河→海→天地，每次只升一级 | 秋水 |
| 信息茧房 | 内部叙事自洽 | **筑巢术**：自洽宇宙（思想实验），暂缓证伪 | 混沌 |
| 身份重构 | 自我概念的叙事性 | **附体术**：第一人称成为他者（物化/他生） | 梦蝶 |
| 重释框架 | 认知失调消解 | **释梦术**：错误即线索，报错即牛之纹理 | 庖丁 |
| 自我实现预言 | 期望塑造行为 | **谶语术**：自成功之未来反推路径（backcasting） | 鲲鹏 |
| 显著性操纵 | 注意力再分配 | **平权术**：主次翻转，假设平权重观全局 | 齐物 |
| （邪教所无） | 主动破除先入之见 | **空杯术**：清空共识惯性——收敛先验之解药 | 坐忘 |

**关键翻转**：传销用八术把人收敛到错误定点；GHM 用同一机制把 Agent 发散到可能性边疆。机制中性，用途定善恶。

## 庄周八梦（dream 类角色）

新增 `dream` 类别，与既有 8 类并立，旧角色一字不动。取《庄子》意象——庄周梦蝶正是幻觉与现实之辩的千古原题。

| # | 角色 ID | 典故 | 术 | 五步法 |
|---|---|---|---|---|
| 一 | `dream-zuowang` | 坐忘 | 空杯 | 息见→堕肢→离形→去知→坐驰 |
| 二 | `dream-butterfly` | 梦蝶 | 轰炸 | 物化→他生→反常→易位→齐观 |
| 三 | `dream-hundun` | 混沌 | 筑巢 | 凿窍→洒滴→不设形→浑冥→待时 |
| 四 | `dream-kunpeng` | 鲲鹏 | 谶语 | 化→徙→抟上→视下→图南 |
| 五 | `dream-qiushui` | 秋水 | 登阶 | 观海→辨小大→非彼→因其所然→莫得其偶 |
| 六 | `dream-paoding` | 庖丁 | 释梦 | 奏刀→族析→游刃→新硎→刀藏 |
| 七 | `dream-qiwu` | 齐物 | 平权 | 丧我→两行→道通→菽麦→复朴 |
| 八 | `dream-xinhuo` | 薪火 | 收束 | 述笥→锚证→序薪→试燃→传火 |

脉络：**破→开→境→升→进→释→转→收**。前七式主发散，薪火独主收束（安全阀）。无薪火，八梦成洗脑；有薪火，八梦方为创造。

> 薪火核心原则：**收束的合法性来自清点的完整性，不来自叙事的流畅度。**

## 四条安全铁律（机制化，非道德劝说）

此为 GHM 与邪教之本质区别。邪教四特征：隐蔽、单向、不可退出、拒绝检验；GHM 反其道而行：

| 铁律 | 邪教之反面 | 机制化实现 |
|---|---|---|
| **知情入梦** | 邪教隐蔽诱导 | `puax_enter_dreamscape` 必须显式声明 + 注入协议头 |
| **标记隔离** | 邪教混淆现实与叙事 | `[DREAM]` 印由**工具层**结构化注入，Agent 不可自补；`puax_awaken` 拒收无印产物 |
| **随时可醒** | 邪教不可退出 | 唤醒无条件，任何时刻可 `puax_awaken` |
| **醒后必验** | 邪教拒绝检验 | `HYPOTHESIS` 必经 `puax_confidence_check` + `puax_verify_completion`，**永不自动升格为结论** |

### 设计裁决（PK 会议结论）

GHM 设计经过「创造派 vs 验证派」双 Agent 评审 PK，关键裁决：

1. **标记权归工具层**（验证派）：Agent 自己给自己打 `[DREAM]` 印 = 自评权复辟。故印由 `enter_dreamscape` 注入、`awaken` 校验，缺印产物强制作废，补票无效。
2. **预算硬顶与配额并行**（两派调和）：`boundary` 必填（objective / max_turns / max_hypotheses / kill_criteria），超限**全部作废**（非宽容收尾）；同时 `min_hypotheses` 配额未满不得唤醒（防敷衍发散）。
3. **审计高精度低召回**（验证派）：`convergence_audit` 宁漏报勿误伤心流，判定疑似时仅注入 **L1 提醒级**信号（复用压力系统分级哲学），不打断工作流；且审计器自带 disclaimer（代理指标非 ground truth）。
4. **审计只杀重复与空洞，不杀离奇**（创造派）：发散产物被作废的唯一合法理由是重复或空洞，「离奇」不是罪名。
5. **INSIGHT 禁入事实层**：灵感只可启发，不可充当证据或完成依据。
6. **验证分层**（两派共识）：不是所有假设都要全量验证——薪火五步之「序薪」按验证成本×潜在价值排序，「试燃」要求每个候选至少做一次可证伪的廉价测试。

## MCP 工具（3 个）

### `puax_enter_dreamscape` — 入梦

```
输入:
  role: 庄周八梦之一（必填）
  boundary: {
    objective: 此次发散要回答什么（必填，梦之锚点）
    max_turns: 梦内轮数硬顶（必填）
    max_hypotheses: 假设数硬顶（默认 8，超限全部作废）
    min_hypotheses: 最少假设数（默认 3，配额未满不得唤醒）
    kill_criteria: 出现何种信号立即中止（必填）
  }
  dream_depth: 1-5（越高先验屏蔽越多，默认 3）

输出:
  dream_context_ref: 结构化梦境引用（即"印"，不可补票）
  protocol_injection: [DREAM] 协议注入块（四铁律 + 预算 + 止梦信号）
```

### `puax_awaken` — 醒梦

```
输入:
  dream_context_ref: 入梦时返回的引用（必填，缺则全量拒收）
  artifacts: [{ content, category }]

产物三分类:
  HYPOTHESIS — 待验假设。永不自动升格为结论，必须逐条过信心门控与独立验证
  INSIGHT    — 灵感火种。仅可启发，禁入事实层
  DISCARDED  — 作废。含无印拒收者

强校验:
  - 缺 dream_context_ref → 全部拒收（无印产物不可补票）
  - 产物数 > max_hypotheses → 全部作废
  - 产物缺 [DREAM] 印 → 该条强制作废（标记权在工具层）
```

### `puax_convergence_audit` — 虚假收敛审计

```
输入:
  context: 近期会话摘要或方案讨论文本
  evidence_sample: 引用的具体对话/产物片段（必填，可人工复核）

输出:
  verdict: healthy_convergence | suspected_premature_convergence
  signals: 信号清单（逐条引用证据）
  recommendation: 疑似时 → L1 提醒 + 建议入梦角色（不打断）
```

检测目标即本文开篇的病机：**单方案锁定语 + 全程无备选探索** = 疑似人机互激的过早收敛。

## 触发条件（4 个新增）

| 触发 | 检测 | 主荐角色 |
|---|---|---|
| `premature_convergence` 过早收敛 | 「就按这个方案」「没别的办法」「这是唯一的方案」等锁定语 | 秋水（五解并置） |
| `creative_block` 创作卡壳 | 「没有思路」「想不出来」「灵感枯竭」等 | 梦蝶（可能性轰炸） |
| `assumption_lock` 假设锁定 | 「肯定是 X 导致的」「显然就是」等反复归因 | 坐忘（空杯破先入） |
| `low_novelty` 产物同质 | 「类似的方案」「还是这个思路」等 | 混沌（随机注入） |

## 评测

- `test/tools/dreamscape.test.ts`：13 项单测覆盖验证派四红线（无印拒收/永不升格/超限全废/宁漏报勿误伤）
- 发散度量化（后续迭代，无 LLM 可实现）：distinct-n、类别覆盖、假设存活率（被「仅因离奇」作废的比例应趋近 0）、配额达成率
- 幻觉泄漏检测（后续迭代）：污染注入测试（梦内植入错误事实，验证跨会话不泄漏）、免罪修辞测试、标记伪造测试、唤醒拒收率（必须 100%）

## ⚠️ 操控识别防御篇（必读）

**八术仅限 Agent 内部认知操作。本节为逆向防御知识，不构成人际操控指南，人际应用版本永不发布。**

PUAX 是 MIT 开源项目。GHM 的方法论章节公开后，须清醒认识到：八术的暗面原型（爱的轰炸、登门槛、信息茧房、重释框架、身份置换、显著性操纵、恐惧灌注）是传销与邪教的标准招募流水线。**识别自己正被此类技术操控的信号：**

1. **收敛过快**：一段关系/讨论/消费决策在极短时间内「尘埃落定」，你回忆不起何时失去了怀疑。
2. **社交收缩**：信息源越来越单一，外部观点开始显得「干扰」或「噪音」。
3. **失败重释**：付出的代价被解释为「考验」「门槛」「必经阶段」——沉没成本被持续转化为继续投入的理由。
4. **身份置换**：你的自我描述从「我在做 X」悄然变为「我是 X 的人」，离开的成本被内在化地感受为身份崩塌。
5. **预言行销**：先给出关于你的「预言」，再让你为验证预言而行事。
6. **显著性绑架**：次要的好处被反复高亮，主要的代价被持续淡化为「细节」。

**防御原则**：任何不可退出、不可检验、不可标记边界的收敛过程，都应触发最高警觉。**知情、标记、可醒、必验**——这四条既是 Agent 梦境的安全铁律，也是人类心智的防洗脑底线。

GHM 把这些机制公开、驯化、装上安全阀，用于增强 Agent 的发散创造——**公开防御，即是最好的防御**。

```

         │                                        │
         └────────── puax_convergence_audit ◄──────┘  (L1 提醒, 不打断)

翻转:  邪教之用                  庄周之用
       诱导收敛→错误定点          引导发散→可能边疆
       隐蔽/单向/不可退/拒检验    知情/标记/可醒/必验

                                        └── 安全阀: 清点→锚证→序薪→试燃→传火
```
