## Что такое PUAX?

PUAX 4.2 — это **когнитивная среда выполнения (Cognitive Runtime)**, созданная специально для автономных ИИ-агентов. Роли — лишь тональные оттенки; настоящее ядро составляют три фундаментальных примитива:

| Примитив | Описание |
|----------|----------|
| **Ситуация (Arena)** | `puax_set_arena`: Соперник + Зрители + Редкий значок (по мотивам эксперимента Крэнмера) для сокрушения посредственности |
| **Шлюзы (Gates)** | Сначала диагностика, Шлюз уверенности, Контракт задачи, Независимая верификация, Перехват PreToolUse |
| **Управляемые сны** | Метод GHM: Осознанный вход, изоляция тегами, мгновенное пробуждение и обязательная проверка результатов (укрощение галлюцинаций) |

Основной путь взаимодействия — пульс `puax_tick` (вызывается нативными хуками среды разработки).

Ключевые возможности:
- **Сжатие Thin Prompt**: `puax_thin_prompt` (minimal/compact/full) экономит >90% токенов (~150 токенов) с оценщиком токенов в реальном времени.
- **Python AMP SDK (без зависимостей)**: Официальное ПО промежуточного слоя со стандартной библиотекой, перехватчиком узлов LangGraph и защитой AutoGen.
- **Гибридное обнаружение триггеров**: YAML-регулярные выражения + семантический TF-IDF.
- **59 мотивационных ролей + пользовательские роли**: Интеллектуальный подбор с обоснованием.
- **Адаптивная маршрутизация по результатам**: `verify_completion` и события прорыва динамически пересчитывают веса в реальном времени.
- **Carbon Shield (Защита человека)**: `puax_audit_manipulation` & `POST /v4/shield/audit` – только обнаружение, манипулирование людьми запрещено. (Расширения для людей отложены; базовое распознавание сохранено)
- **Мультимодельный бенчмарк AMB**: 12 сценариев × 5 профилей моделей (+39.2% к успешному ремонту, +60.0% к обнаружению скрытых дефектов).
- **Настройка в один клик Host Doctor**: `npx puax doctor --fix` устанавливает хуки для 10 ведущих хостов (Cursor, Claude Code, Windsurf, Trae и др.).
- **Система хуков и уровни давления**: L0–L4 с автоматическим снижением давления после подтвержденного прорыва.
- **Самоэволюция**: Шрамы, ранги и веса в `~/.puax/evolution.json`.

## Быстрый старт

```bash
# Режим клиента MCP (STDIO, Рекомендуется)
npx puax-mcp-server --stdio

# Режим HTTP
npx puax-mcp-server --port 2333
```
